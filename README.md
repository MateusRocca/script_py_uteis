# 🐍 Python Utilities & Automations

Repositório criado para armazenar **códigos, scripts, automações e ferramentas úteis desenvolvidos em Python**.

A ideia é centralizar projetos e soluções que possam ser reutilizados em diferentes contextos, principalmente envolvendo **automação de processos, manipulação de dados, interfaces gráficas e integração com sistemas**.

## 📂 Conteúdo

Este repositório pode conter diferentes tipos de projetos, como:

* 🤖 Automações de processos
* 🌐 Automação de navegadores com Playwright
* 🖥️ Interfaces gráficas com CustomTkinter
* 📊 Manipulação e tratamento de dados
* 📁 Automação de arquivos e pastas
* 🔗 Integrações com sistemas e serviços
* ⚙️ Scripts para tarefas repetitivas
* 🧰 Utilitários e ferramentas auxiliares

## 🛠️ Tecnologias

As tecnologias utilizadas variam de acordo com cada projeto. Entre as principais:

* **Python**
* **Playwright**
* **CustomTkinter**
* **Pandas**
* **OpenPyXL**
* **Requests**
* **Selenium**

Novas bibliotecas podem ser adicionadas conforme a necessidade de cada projeto.

## 🚀 Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
```

### 2. Entre na pasta

```bash
cd SEU-REPOSITORIO
```

### 3. Crie um ambiente virtual

```bash
python -m venv .venv
```

### 4. Ative o ambiente virtual no Windows

```powershell
.venv\Scripts\Activate.ps1
```

### 5. Instale as dependências

Cada projeto pode possuir seu próprio `requirements.txt`.

```bash
pip install -r requirements.txt
```

### 6. Execute o projeto

```bash
python main.py
```

> Consulte o `README.md` de cada projeto quando houver instruções específicas.
